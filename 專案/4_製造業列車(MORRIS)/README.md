## 這站的兩個特殊設定

**1. 掃 QR Code 進來直接停在報名表**

外部發出去的 QR Code 指向站台首頁,掃進來的人反映還要自己往下捲才找得到報名。現在開啟後會自動定位到報名區:

- 網址有帶錨點(`#why`、`#curriculum` 等)則不介入,維持原行為
- 使用者一有捲動 / 觸控 / 按鍵就停止介入,往上捲一樣看得到完整課程介紹
- 上方照片牆與梯次資料載入會把版面往下推,程式會持續校正 6 秒到位置穩定

**2. 場次來自本站自己的 Sheet**

原本兩站共用一份梯次目錄、靠「單場講師」欄過濾,2026-09-24 已分家:台北雙講師那列搬到專案 7,本站 Sheet 只留 Morris 場,前端不再過濾,**列幾場就顯示幾場**。

「單場講師」欄仍建議填 Morris、「單場主題」填這場的內容 —— 報名確認信會引用這兩欄。
