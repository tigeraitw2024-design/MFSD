# 設計風格 · 深藍 Tech Summit

> 用戶要求風格參考「飛書 2022 春季未來無限大會」海報:深藍底 + 電光藍漸層 + 人物卡片 grid。
> 跟前 3 個專案(1 深橄欖、2 MIID 紅黑、3 薄荷亮色)徹底切開。

---

## 主色

- **底色**:`#0A1128`(深靛,不用純黑,帶點藍)
- **底色暗**:`#050914`(深區塊、大 header)
- **主色藍**:`#0066FF`(電光藍 · CTA、標題強調)
- **主色亮**:`#4D9FFF`(hover、卡片邊框發光)
- **主色深**:`#003D99`(漸層深端)
- **卡片藍漸層**:`linear-gradient(135deg, #0066FF → #003D99)`(人物照底)
- **強調 accent**:`#00E5FF`(cyan 電光,少量使用點綴)
- **文字白**:`#FFFFFF`
- **文字灰白**:`rgba(255,255,255,0.75)`
- **文字灰**:`rgba(255,255,255,0.55)`
- **線 / 邊框**:`rgba(255,255,255,0.08)`

## 質感

**深藍 Tech Summit · Corporate Conference Poster**

- **不用**亮底/mint/暖色(那是 3 的視覺)
- **不用**斜角/紅色/硬陰影(那是 2)
- 用:**深藍底 + 電光藍漸層卡 + 大量幾何裝飾 + tech grid 線條**
- 有些**斜切裝飾色塊**在角落(呼應飛書海報的斜角)
- 人物照用**藍漸層卡片**包起來(不是純去背貼在深底,是有 frame)
- 標題大而粗、白字、置左

## 字體

- 中文:Noto Sans TC(400 / 700 / 900)
- 英文/數字:Inter(400 / 500 / 700 / 900)
- 數字大量使用(日期、梯次數字)可以放大成 accent

## 一句話講你想給訪客的感覺

「這是一場**製造業巡迴 tech summit**,跟以前紅通通的政府培訓、亮亮的顧問課完全不同 — 進來像進入 keynote 會場,有科技感、有專業感、有 momentum。」

## 避開什麼

- **不用**mint、cream、off-white(那是 3)
- **不用**紅色主色、MIID 斜角、硬陰影(那是 2)
- **不用**橄欖綠、政府單位 vibe(那是 1)
- 不做過度動畫 — 深底配過度發光會像遊戲網站
- 不放講師照片以外的 stock photo — 保持乾淨
