# [這個專案叫什麼] — 素材資料

這個資料夾裝的是這個專案的所有原始素材。
把 `1. 素材資料/` 裡面該填的填一填,對 Claude 說「跑 [這個專案名]」就會開工。

---

## 「1. 素材資料」裡的檔案清單

| 檔案 | 必填? | 一句話說明 |
|---|---|---|
| `品牌.md` | ✅ 必填 | 主色、字體氣質、視覺風格 |
| `課程.md` | ✅ 必填 | 課程主體:標題、副標、對象、時長 |
| `情境.md` | ✅ 必填 | 3 條自動化流程(或 3 個關鍵成果) |
| `聯絡.md` | ✅ 必填 | Footer 聯絡窗口 |
| `講師.md` | ⭕ 選填 | 講師介紹,不填 = 走「無講師版」 |
| `梯次.csv` | ⭕ 選填 | 開課場次,或改貼 Google Sheet URL |
| `確認信.md` | ⭕ 選填 | 報名確認信文案自訂 |
| `資格審查.md` | ⭕ 選填 | 統編驗證規則,不填 = 任何人都能報名 |
| `素材/` | ⭕ 選填 | Logo、Hero、OG 分享卡 |

---

## 「2. 產出」是什麼

Claude 讀完 `1. 素材資料/` 後,產出的完整網站會放在這裡:

```
2. 產出/
  index.html          ← 完整網站
  assets/             ← 引用的資產(logo、hero、favicon 等)
```

你可以本地開 http server 先看,或直接 push 上線。
