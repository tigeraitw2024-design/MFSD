# 頁面結構

**一個標準的課程網站有這些章節,順序固定,可依專案增減。**

---

## 版面順序

```
[NAV]                     置頂:Logo + 導覽連結 + 立即報名 CTA
[HERO]                    主標 + 副標 + 3 個成果關鍵詞 + 主視覺 (SVG 或照片)
[01 為什麼上這堂課]        3 張風險卡 + 課後你會得到 3 條
[02 我們的教法]            課程定位 body + 3 個特色
[03 課程架構 U1~U5]        5 張任務卡(左)+ AX 成熟度金字塔(右,sticky)
[03 U4 詳細展開]           3 條自動化流程(現況/情境/成品 + SVG 流程圖) ⭐ 核心區塊
[04 課程特色]              5 張小卡橫排
[05 課完,你能做這些事]     4 張具體成果卡
[06 這堂課給誰上]          4 張適合對象卡
[07 講師介紹]              (可選,無講師版整章移除、後續章節遞補編號)
[07/08 開課梯次]           Carousel 卡,即時顯示剩餘名額
[08/09 課程報名]           STEP 1 統編驗證(可選 g0v)→ STEP 2 表單
[09/10 常見問題]           FAQ 手風琴
[FOOTER]                   聯絡窗口 + 跨站連結 + 版權
```

## 各章的必要性

| 章節 | 必要? | 說明 |
|---|---|---|
| Nav / Hero | ✅必要 | 沒這兩塊就不是網站 |
| 01 為什麼 | ✅必要 | 給訪客一開始就知道「這個課解決什麼問題」 |
| 02 教法 | ⭕可選 | 想強調課程風格才放,不然可以合併到 01 |
| 03 課程架構 U1~U5 | ✅必要 | 課程主體 |
| 03 U4 深度展開 | ✅必要 | **這是這個套版最核心的資產** — 3 條具體場景 + SVG |
| 04 特色 | ⭕可選 | 有的話 5 張橫排,沒的話省掉 |
| 05 學習成果 | ✅必要 | 「課完能做什麼」是關鍵決策點 |
| 06 適合對象 | ⭕可選 | 幫訪客自我判斷 |
| 07 講師 | ⭕可選 | 有講師才放,無講師版整章拿掉 |
| 08 梯次 | ✅必要(有實體才) | 純線上課可以拿掉,改成「隨時開課」 |
| 09 報名表單 | ✅必要 | 主要 CTA 落地 |
| 10 FAQ | ⭕可選 | 免費課通常 3-5 題就夠 |
| Footer | ✅必要 | 聯絡資訊 + 版權 |

## 章節間的動效

- Section eyebrow 用 `01 ／ 章節名稱`,金色小字,有兩條金色平行線
- 卡片有 `.reveal.from-left / from-right / from-up` 捲動進場動畫
- U4 三張流程卡有交錯的左右佈局(01 左字右圖 / 02 左圖右字 / 03 左字右圖)
- SVG 內的節點、齒輪、資料流線條要有 `<animate>` 動畫但要輕(不能搶注意力)

## 新專案套用時的判斷

如果客戶的 `情境.md` 只有 2 條,U4 展開就只做 2 條,不硬湊。
如果客戶沒 `講師.md`,自動走無講師版,章節編號從 07 直接跳到「開課梯次 07」。
如果客戶沒 `梯次.csv`,梯次章節顯示「敬請期待」+ 一個「訂閱開課通知」按鈕。
