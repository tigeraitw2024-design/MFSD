# 視覺系統

**把 `品牌.md` 的 hex 色 + 質感關鍵字,轉成實際 Tailwind class + CSS variables 的規則。**

---

## Step 1:讀「質感關鍵字」決定基底

| 關鍵字 | 底色風格 | 字體傾向 | 動效 |
|---|---|---|---|
| 奢華 / 沉穩 | 深黑 + 金色線條 | 大字距、粗體、Noto Sans TC 900 | 慢速 float、光暈 orb |
| 專業 / 冷靜 | 深藍 / 灰白極簡 | 中距、Inter / Manrope | 幾何線條、克制動效 |
| 溫暖 / 手感 | 米色 / 奶油白 | 微襯線、圓角 | 手繪線稿、輕彈跳 |
| 科技 / 銳利 | 黑 + 螢光綠 / 電光藍 | 等寬字、Grotesk | 格線閃動、掃描線 |
| 學術 / 典雅 | 藏青 + 象牙白 | 襯線 (Songti / Noto Serif) | 極簡淡入 |

## Step 2:hex 色 → CSS variables

不論質感,結構固定:

```css
:root {
  --brand-primary: #____;      /* 主色,從品牌.md 抄 */
  --brand-primary-light: #____;/* 主色亮版,強調用 */
  --brand-bg: #____;           /* 底色 */
  --brand-bg-2: #____;         /* 次深(半透明區塊底) */
  --text-primary: #____;       /* 主文字 */
  --text-secondary: rgba(...); /* 灰階副文字 */
}
```

## Step 3:Tailwind config 對應

Hero 主標題:`text-white font-black text-5xl sm:text-6xl md:text-7xl`
金色強調:`text-gold-light font-bold`(在 tailwind.config 中定義 `gold-light: #F2D88B`)
背景光暈:`.gold-orb`(絕對定位大圓 + 徑向漸層 + blur)

## Step 4:Hero 主視覺決策樹

```
講師.md 有填?
├── 有 → Hero 左邊放講師照片(半透明底 + 金框)
└── 沒有 → Hero 左邊用 SVG 手繪
              ├── 質感=奢華 → 廠房剪影 + 齒輪 + 資料流(製造業課程這版)
              ├── 質感=科技 → 3D 幾何 + 電路 + 節點
              ├── 質感=學術 → 幾何三角 + 圖書意象
              └── 其他 → 抽象金色線條組合
```

## Step 5:預設對應(製造業課程這版)

金黑主題的實際 Tailwind config:

```js
colors: {
  gold: '#D8B25A',
  'gold-light': '#F2D88B',
  navy: {
    900: '#0B0805',
    800: '#161009',
    700: '#1F1709',
  }
}
```

Card 樣式:
- `.card-gold`:金黑漸層底 + 金色邊框
- `.card-glass`:半透明黑底 + 微金色邊 + backdrop-blur
- `.glow-border`:hover 時金光暈邊
- `.btn-gold`:金色實心按鈕(用於主 CTA)

新專案適用時,把上面的 `gold` 換成客戶主色,`navy-*` 換成客戶底色系,結構不用重寫。
