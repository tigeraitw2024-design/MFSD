# 部署清單

**Claude 產出 `2. 產出/index.html` 之後,你要人工做的三件事(每個新網站一次)。**

---

## ① Cloudflare Pages 新增專案

1. 進 [Cloudflare Dashboard](https://dash.cloudflare.com) → Pages
2. Create a project → **Connect to Git** → 選 MFSD Repo
3. Set up builds and deployments:
   - Project name:`[你想要的專案 slug]`(例:`iot-workshop`)
   - Production branch:`main`
   - Framework preset:**None**
   - Build command:**留空**
   - Build output directory:`專案/[專案名]/2. 產出`
4. Save and Deploy → 拿到 `xxx.pages.dev`

**替換自訂網域**(選,不做也 OK):
- Cloudflare Pages → Custom domains → Set up a custom domain → 輸入 `xxx.tigerai.tw`

---

## ② Apps Script 部署

**選項 A:沿用同一個 Apps Script**(共用一個 Google Sheet)
- 不用做任何事,SHEET_WEBHOOK 直接沿用 MFSD 那個
- **好處**:所有報名資料集中在一份 Sheet 好管理
- **壞處**:客戶看得到 Sheet 名稱(除非另建分頁)

**選項 B:新開一個 Apps Script + 新的 Google Sheet**
1. 建新 Google Sheet(空的)
2. Sheet → 擴充功能 → Apps Script
3. 貼入 `landing/google-apps-script.js`
4. 改第 22 行 `SHEET_ID` 為新 Sheet 的 ID
5. 部署 → 新增部署 → 網頁應用程式:
   - 執行身份:**我**
   - 存取權限:**任何人**
6. 一路授權 → 拿到 Web App URL(這是新的 SHEET_WEBHOOK)

## ③ 貼 SHEET_WEBHOOK 回產出 HTML

打開 `專案/[專案名]/2. 產出/index.html`
找到 `CONFIG.SHEET_WEBHOOK = '...';`
把 ② 拿到的 URL 貼上去

commit + push → Cloudflare 自動重新部署 → 完成

## 驗收 checklist

- [ ] `xxx.pages.dev` 打得開,沒 404
- [ ] STEP 1 統編驗證(如果有啟用)能查到公司
- [ ] STEP 2 表單填完送出,不會噴錯
- [ ] Google Sheet 出現一筆新資料
- [ ] 你自己信箱收到「報名確認」信

四個都 ✓ 就上線成功。

---

## 常見錯誤排除

| 症狀 | 原因 |
|---|---|
| `xxx.pages.dev` 顯示 landing 內容,不是 course | Cloudflare Build output directory 設錯,重看 ① |
| 表單送出後噴 CORS 錯 | Apps Script 部署時「存取權限」沒選「任何人」 |
| Sheet 沒新增資料 | SHEET_WEBHOOK URL 貼錯,或 Apps Script 沒重部署 |
| 收不到確認信 | Apps Script 的 Gmail 授權過期,回編輯器重新執行任一函式重新授權 |
