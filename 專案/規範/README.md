# 規範 — Claude 建站時遵守的規則

**這個資料夾你不用改,是 Claude 建站時會讀的參考規範。**

每次收到「跑 [專案名]」的指令,Claude 會:
1. 讀 `[專案名]/1. 素材資料/` 拿到客戶特定資訊
2. 讀 `規範/` 底下的檔案拿到「怎麼建」的通用規則
3. 綜合兩邊產出 `[專案名]/2. 產出/index.html`

---

## 檔案清單

| 檔案 | 用途 |
|---|---|
| `文案原則.md` | 什麼字要禁用、抽象怎麼變具體、辯護句怎麼改正面列舉 |
| `頁面結構.md` | 一個課程網站有哪些章節、每章的功能、順序不能亂 |
| `視覺系統.md` | 品牌.md 的 hex 色如何對應到 Tailwind class + CSS variables |
| `部署清單.md` | 產出後你要人工做的三件事(Cloudflare / Apps Script / SHEET_WEBHOOK) |

## 什麼時候會更新這個資料夾?

當我們一起處理某個新專案,發現某條規則不夠明確或漏掉一種情境,就會更新到這裡。
你不用主動維護,但如果覺得某條規則寫壞了跟我說。
