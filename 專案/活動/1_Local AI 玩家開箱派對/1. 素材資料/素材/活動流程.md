# 11/4 OOPS｜Local AI 玩家開箱派對 × Free Token Server 展示 × OOPS Afterparty｜流程建議稿

> 活動日期：2026/11/04（三）。以下是供張凱榮、Morris、Andy 與合作方討論的流程提案，不是已核定時刻表。OOPS 可用時段、案例分享者、合作方出席與 Token Demo 狀態確認後再定時間。

## 流程設計原則

活動先用 Local AI 案例和玩家展示製造真實參與理由，再在現場展示虎智設備與產品；讓主要合作方看見真實反應後，安排合作交流，晚上以 Networking 延續。基本分是合作方認可角色及後續行動；來賓數、體驗與擴散是加分。流程不以尚未核准的價格或分潤作宣傳內容。

## 重要執行條件

- 時段是排程模型，須依 OOPS 場地及 Andy 確認結果調整；保留晚上 Networking。
- 撼訊先由張凱榮／虎智合作窗口向撼訊主管請示合作方式，再確認是否安排公開環節；也可於活動現場與撼訊代表直接討論。
- OOPS 設備採購價格不放進活動宣傳或現場簡報；有興趣的客戶直接轉給虎智聯繫。Token 單筆費用與分潤也暫不列入對外資訊。
- Token 流程只有在技術端到端測試通過後才安排掃碼體驗。測試未通過，使用 Server 展示、操作影片或情境流程示意。
- 參與人數、案例分享者、合作方出席、產品能力與對外合作內容均以實際確認為準。
- 網站提供「我要上台展示 AI」與「我要報名參加」兩個入口；講者／Demo 投稿經後台精選勾選後，最多展示 2–3 位。Afterparty 可選擇加報並折抵 NT$50；票務與酒水細節待 OOPS 提供。
- 會前指定主持、紀錄、Demo、報到、合作洽談及 follow-up 負責人；會後追蹤依 [籌備追蹤清單](./checklist.md) 執行。
