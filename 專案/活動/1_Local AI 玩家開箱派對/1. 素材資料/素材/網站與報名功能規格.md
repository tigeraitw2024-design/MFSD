# 11/04 活動網站與報名功能規格（規劃稿）

> 本文件定義活動頁需要的兩個報名入口。網站／表單技術尚未指定；OOPS Afterparty 票價、酒水內容與付款方式待 OOPS 提供後補齊。

## 活動頁首頁

活動頁使用一頁式結構，先呈現參與者能看的案例和體驗，再提供兩條清楚入口：

1. **我要上台展示 AI**：提交講者／Demo 申請。
2. **我要報名參加**：一般活動報名，可選擇加報 OOPS Afterparty 並折抵 NT$50。

建議主標：**Local AI 玩家開箱派對**。副標可用「真實案例展演 × Server 體驗 × 晚間交流」。若 Token 體驗尚未完成技術驗收，先不在首屏承諾免費 Token。

首頁內容順序：活動主張與日期／地點 → 兩個入口按鈕 → 已確認講者／案例展示 → 活動亮點與流程 → 一般報名與 Afterparty 說明 → 交通／常見問題。

## 入口 A：講者／AI Demo 申請

### 申請者流程

提供獨立按鈕「我要上台展示 AI」。申請表收集：

- 姓名／公開稱呼、職稱或專長、聯絡方式。
- AI 專案／應用名稱、解決的問題、現場想 Demo 的內容。
- 展示形式、預計所需時間、設備／網路／電力需求。
- 支援資料：PDF、作品連結或影片連結；若採上傳影片，限制格式與檔案大小由網站實作方核定。
- 公開授權：申請者確認有權提交該資料，並選擇是否同意將所選資料展示在活動頁及活動宣傳中。
- 收件告知：提交申請不等於保證入選；主辦方會以提供的聯絡方式回覆。

申請者送出後看到「已收到，等待主辦方聯繫」，不直接自動刊登。

### 後台審核與精選展示

後台至少有申請列表、申請內容／附件檢視、聯絡狀態，以及「精選並公開」勾選欄位。勾選後才可在前台講者／案例區顯示；取消勾選即下架。前台精選名額最多 2–3 位，避免報名者誤以為所有投稿都已獲選。

前台講者卡片顯示公開稱呼、職稱／專長、案例名稱、簡介、核准的 PDF／作品連結或影片，以及「此人將展示什麼」。只顯示申請者已授權、且主辦方核准的欄位與檔案。未獲選者資料不公開。

## 入口 B：一般活動報名與 OOPS Afterparty

### 報名者流程

一般活動報名頁單獨可完成報名；表單中另設可選項：

- □ 只參加一般活動
- □ 加報 OOPS Afterparty，享票價折抵 NT$50

參加 Afterparty 是自選項，不影響一般活動報名。選擇後顯示 OOPS 確認的 Afterparty 原價、NT$50 折抵及折後金額；目前只確認折抵 NT$50，原價、酒水包含項目、付款方式、退費／取消規則及名額尚待 OOPS 提供。資訊未齊前可先記錄意願／保留名額，不收取未核定金額。

### 報名資料與交接

- 一般活動和 Afterparty 分開記錄報名／出席狀態，方便現場名單與人數核對。
- OOPS 負責 Afterparty 的主辦與票務資訊；參加者資料只有在告知用途並取得同意後，才提供 OOPS 完成 Afterparty 報到／聯繫。
- 確認主辦方各自可存取的欄位、資料保存期限、取消／退款聯絡窗口。
- 報名完成頁與確認通知分別列出一般活動資訊、Afterparty 選擇和待補的 OOPS 資訊。

## 後台與成效追蹤

後台需能匯出或查看：一般報名數、Afterparty 加報數、講者／Demo 申請數、已精選公開數、報名來源、實際出席與 Afterparty 報到。講者投稿資料與一般報名資料分權管理，不把未公開的投稿附件放在公開網址。

## 上線前要補齊

- [ ] 活動正式名稱、OOPS 場地地址與活動時段。
- [ ] 一般活動是否收費、名額、報名截止時間與取消規則。
- [ ] 講者／Demo 申請截止時間、選取通知日期、展示時長和現場設備條件。
- [ ] PDF／影片的接受格式、大小限制、存放方式與公開授權文字。
- [ ] OOPS Afterparty 原價、酒水／餐食包含內容、折抵後金額、付款方式、名額及退費規則。
- [ ] Afterparty 報名資料如何安全交給 OOPS，以及現場核銷方式。
- [ ] Token 體驗是否通過外部測試；通過才列入網站宣傳。
