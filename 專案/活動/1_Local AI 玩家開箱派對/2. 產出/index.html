05 / // FAQ

常見問題

活動要收費嗎?
一般活動費用與名額依最終公告為準。Afterparty 原價由 OOPS 公告 · 憑本頁報名可折抵 NT$100。
我送出「我要上台展示 AI」就會被安排上台嗎?
不會。所有投稿會進主辦審核 · 精選名額最多 3 位。入選我們會用你留的 email 聯繫 · 未入選者資料不會公開展示。
現場有 Free Token 可以體驗嗎?
是。但 Token 體驗流程須通過技術驗收後才會開放現場掃碼。未通過前以 Server 展示、操作影片、流程示意呈現。
我不是技術人員 · 也能來嗎?
可以。現場有產品介紹、合作流程說明、硬體 Demo · 不需要寫程式。
Afterparty 一定要加報嗎?
不一定。Afterparty 是自選加報項目 · 只參加一般活動完全沒問題。
活動流程會跟報名簡介完全一樣嗎?
目前流程為暫定模型 · 實際時段依場地與合作方最終確認結果微調。活動前 1 週會寄 email 通知最終時間表。
