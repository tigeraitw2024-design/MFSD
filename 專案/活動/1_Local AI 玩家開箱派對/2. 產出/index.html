06 / // FAQ

常見問題 Frequently Asked

活動要收費嗎? Is there a fee?
白天的實體活動免費參加 · 名額依最終公告為準。晚上派對由 OOPS 主辦 · 需付費參加 · 原價由 OOPS 公告 · 憑本頁報名可折抵 NT$100。 Daytime event is free · seat count per final announcement. Afterparty is paid (hosted by OOPS, price TBA) · NT$100 off via this signup.
我送出「我要上台展示 AI 作品」就會被安排上台嗎? Does submitting "I'll Demo My AI" mean I'm on stage?
不會。所有投稿會進主辦審核 · 精選名額最多 10 人。入選我們會用你留的 email 聯繫 · 入選者可免費獲得晚上派對入場券 · 未入選者資料不會公開展示。 No. All submissions enter host review · up to 3 selected. We'll email you if picked · non-selected submissions stay private.
現場有 Free Token 可以體驗嗎? Can I actually try Free Token on-site?
是。現場會依當日系統狀態 · 提供掃碼體驗或 Server 展示 / 操作影片 · 兩者都能看到實際運作。 Yes. Depending on system readiness that day · either live QR hands-on or Server demo + walkthrough video — both show real behavior.
我不是技術人員 · 也能來嗎? I'm non-technical · can I still come?
可以。現場有產品介紹、合作流程說明、硬體 Demo · 不需要寫程式。 Yes. Product intro · partner flow walkthrough · hardware demo — no coding required.
晚上派對一定要加報嗎? Do I have to opt into Afterparty?
不一定。晚上派對是自選加報項目 · 只參加一般活動完全沒問題。 No. Afterparty is an optional add-on · joining only the main event is fine.
