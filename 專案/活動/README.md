# 活動類專案

這裡放活動類網站(說明會、研討會、單場活動、發表會等)· 跟課程類不同:
- 通常只有一頁(活動頁 + 報名)
- 沒有梯次 / 沒有多講師結構
- 可能沒有 Apps Script(用 Google 表單或 Lu.ma 代替)
- 規模較小 · 製作週期較短

## 要新增活動

直接跟 Claude 說「要新增一個活動網頁」· 給一份活動資訊:
- 活動名、時間、地點、對象
- 流程 / 議程
- 講者或主辦
- 報名方式(Google 表單連結 / Lu.ma / 另外做 Apps Script)
- 設計風格要求

Claude 會做在 `專案/活動/[活動名]/` · 第一個做完後會抽出範本放回 `專案/活動/範本/`。

## 跟課程類的共用資源

活動類網站也可以吃 `/_shared/pstrip.js` 跟 `/_shared/media_manifest.json`(活動現場照片輪播)· 做法跟課程類一樣。
