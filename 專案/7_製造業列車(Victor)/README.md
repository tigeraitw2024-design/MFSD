## 上線前你要做的兩件事

**1. 開自己的報名後端(重要)**

目前 `SHEET_WEBHOOK` 還指向專案 4 的 Apps Script,**這站的報名會寫進 MORRIS 那份 Sheet**。請:

1. 新開一份 Google Sheet,複製網址裡的 ID
2. 擴充功能 → Apps Script → 貼上本資料夾的 `apps-script.js`
3. 把 ID 填進檔案開頭的 `SHEET_ID`
4. 執行 `setupAll` → 授權(需要 Sheet 與 Gmail 寄信權限)
5. 部署 → 新增部署 → 網頁應用程式(執行身份「我」、存取權「任何人」)
6. 把 Web App URL 給 Claude 換進 `course-tour-victor/index.html`

**2. 決定梯次目錄要不要也分開**

換上新 Sheet 後,這站的 `COHORTS_CSV_URL` 也要換成新 Sheet 的第 1 分頁(發布到網路 → CSV)。在那之前兩站共用同一份梯次目錄,靠「單場講師」欄分辨,功能正常。
