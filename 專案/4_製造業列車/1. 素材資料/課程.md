## 課程架構(4 單元 · 2 位講師)

### 上半場 · Morris — AI 落地實戰(3 小時 · 4 單元)

**單元 01 · 製造業 AI 落地地圖**(30 min · 講授)
- 為什麼是現在?Agentic AI 時代不談 ROI
- 製造業三大 AI Solution Map:
  - 訂單客服助理(SKU/報價/翻譯/ERP)
  - 生產效能分析助理(MES/OEE/異常告警)
  - 產線設備維修助理(SOP/故障診斷)
- 「聽了很多 AI,不知道從哪動」→ 給地圖

**單元 02 · Workshop:Antigravity 把 SOP 變成 AI Skill**(60 min · 實作)
- Google Antigravity Agentic IDE 概論
- Vibe Coding 工作模式
- 學員實作:把自己部門的一份 SOP 寫成可執行的 AI Skill(SKILL.md + scripts + references 結構)
- 產出:一個能重複跑的合約/報價/巡檢 Agent

**單元 03 · Workshop:n8n 全流程自動化**(60 min · 實作)
- n8n 介面、節點類型(Trigger / App Action / Core / Cluster)
- 手把手 Nathan 訂單案例:HTTP Request → If 過濾 → Set 整理 → Code 計算 → Discord 通知 → 每週排程
- 學員實作:改造成自己公司的一條自動化(如報表週會、庫存告警、訂單分派)
- 匯出 / 版本控管 / 執行紀錄

**單元 04 · 企業 AI 治理入門**(30 min · 講授)
- Enterprise AI Orchestrator 概念:散落的 AI 收攏成中央 Hub
- 銜接下半場資安主題

### 下半場 · Victor — AI 資安實戰(3 小時 · 4 單元)

**單元 05 · LLM 的資安死角**(30 min · 講授)
- 訓練資料汙染、模型偏移、Prompt 洩漏、API 濫用、上下文限制
- 為什麼「工控/工業」跟「AI 資安」必須一起看
- 案例:一句話問答洩漏公司報價、Agent 越權操作、Skill 被劫持

**單元 06 · 2026 資安新戰場:AI Agent 攻擊面**(30 min · 講授)
- 當員工開始用 AI Agent 幫忙做事,權限、資料、對外通訊變成新破口
- MCP / CLI / 自動執行 → 全新攻擊向量
- 對照 Morris 上午教的 n8n + Antigravity → 這些工具跑起來會有什麼風險

**單元 07 · Workshop:OpenClaw 安全 Gateway 實作**(75 min · 實作)
- Victor 開源的 AI-native Gateway(MIT 授權)
- 學員實作:
  - 安裝 openclaw CLI / 設 API 金鑰
  - 開啟 Skills、MacOS 授權 TCC(自動化/通知/螢幕錄影)
  - 接 WhatsApp / Telegram / Discord
  - 心跳監控(15 min 檢查一次)
- 產出:給上午做的 AI Agent 加上一道安全門

**單元 08 · AI 治理實務 + 收尾**(45 min · 講授 + Q&A)
- 「AI 最危險的不是駭客,是什麼都相信它的員工」
- 企業 AI 治理 checklist(權限、稽核、資料流)
- 完訓帶走什麼:AI Skill + n8n 流程 + OpenClaw Gateway 三個能上工的東西

## 3 個帶走的成果(給 Landing 用)

1. **能跑的 AI Skill**:把公司一份 SOP 變成可重複執行的 AI 工作模式

3. **能守的安全 Gateway**:上面兩個工具加上 OpenClaw,權限稽核、心跳監控就位
