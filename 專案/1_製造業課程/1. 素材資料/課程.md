# 課程資料

## 基本資訊

- **課程名稱**:製造業銷售流程導入 AI 工具
- **副標**:經銷商業績追蹤 ・ 銷售週報自動產出 ・ 客服訊息自動分類
- **對象**:製造業老闆 / 主管、業務 / 行銷、客服 / 業助、行政 / PM
- **總時數**:6 小時
- **天數**:1 天
- **型態**:實體
- **每梯人數上限**:20 人
- **收費**:免費(限「完全符合資格」之企業)

## 一句話說明

6 小時實戰,帶 3 條馬上能上線的自動化流程:每週一自動產週報、客戶 LINE 訊息自動分流、大客戶斷單自動告警。每一步都看得到、查得到、改得動。

## 學員帶走什麼(3 條自動化流程)

### 成果 01 · 自動週報

**執行頻率**:每週一 08:00

**現況痛點**
業助每週一早上花 1.5 小時手動拉 Excel、拼數字、做 PPT,主管開晨會前還在等。

**使用情境**
王經理以前週一 7:30 進辦公室拼週報,拼到 9:30 才能開晨會。課後第二週,他直接 8:00 打開信箱:「上週訂單 327 筆、Top 3 客戶、本週需注意的 5 個品項」一封信全在裡面,9:00 直接帶進晨會用。

**帶走的成品**
- 一個 n8n 流程檔,每週一自動執行,不用人按
- 從 Google Sheets / Excel 抓上週訂單,AI 自動分類整理
- 產出固定格式的 HTML 週報,直接寄到指定主管信箱
- 失敗會自動 LINE 通知你,不會默默漏掉

---

### 成果 02 · 客服訊息自動分流

**執行頻率**:訊息進來即時觸發

**現況痛點**
官方 LINE 跟客服信箱每天進 30~50 封,報價、催貨、抱怨混在一起,業助一封一封手動轉,常常卡 2-3 小時才送到正確窗口。

**使用情境**
客戶上午 10:00 在官方 LINE 留言「上次那批貨什麼時候到?」10:00:30 系統判讀為「出貨進度詢問」,自動推給業助群組,並貼上客戶名 + 最近 3 張訂單編號。業助 10:05 就回完。客戶等待從半天縮到 5 分鐘。

**帶走的成品**
- 一個 n8n 流程,串接 LINE 官方帳號 / Email / 表單
- AI 自動判讀 5 種意圖類別(報價、規格、出貨、客訴、其他)
- 不同類別自動轉到對應部門的 LINE 群組,附上客戶歷史摘要
- 「緊急/抱怨」類別會額外 push 給主管,不會被漏接

---

### 成果 03 · 績效異常告警

**執行頻率**:每天凌晨自動掃描

**現況痛點**
月底結算才發現大客戶 A 已經連兩週沒下單、品項 B 的退貨率突然飆 3 倍。等發現都晚了,業務才開始補救。

**使用情境**
週二早上 9:00,業務組長 LINE 跳出通知:「⚠ 客戶 A 已 7 天無新訂單,上月同期 12 單。建議今天致電。」當天下午就打過去關心,發現是窗口換人 —— 比月底才發現整整早了 3 週。

**帶走的成品**
- 一個 n8n 流程,每天凌晨自動讀 ERP / Sheets 訂單資料
- 用你設定的規則 + AI 判斷異常(單量驟降、退貨飆高、應收逾期)
- 有異常的當天早上 LINE 推播主管,附帶對比數字
- 沒異常的日子不會打擾 —— 只有真的要看才會跳

## 其他特殊需求

### 資格審查(統編驗證)
用 g0v API 查 → 4 條規則全過才能報名:
1. 公司營業狀態正常(不是歇業/解散/撤銷)
2. C 大類製造業(行業代碼前 2 碼 08~34)
3. 工具機上下游代碼白名單
4. 勞工投保人數 200 人以下(**使用者在 STEP 1 自行勾選**,g0v 無此資料)

### 報名截止規則
- 開課當天起停止報名(前一天 23:59 仍可報)
- 額滿仍可登記候補,有缺會遞補

姓名 / 職稱 / 電話 / Email / 年齡 / 身分證字號 / 公司人數(1~30 / 31~100 / 101~199)
