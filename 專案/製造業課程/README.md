## 對照建議

如果你要建自己的新專案:

1. 先看你這個 `1. 素材資料/情境.md` — 3 條自動化流程 怎麼寫得具體、有數字、有畫面
2. 再看 `2. 產出/index.html` — 從素材變成的完整網站
3. 覺得 OK 就複製 `專案/範本/` 開始填自己的
