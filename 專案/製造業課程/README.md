# 製造業課程 — 完整範例專案

這是套版系統的**第一個真實成品**,現在跑在 https://mfsd.pages.dev/course/

如果你要建新專案,先看這個資料夾,就能知道:
- `課程.md` 跟 `設計風格.md` 實際要寫多滿
- 產出的 `index.html` 長什麼樣
- 從素材到產出,可以做到什麼程度

---

## 資料夾結構

```
製造業課程/
  1. 素材資料/
    課程.md              → 課程全部資訊(名字、對象、3 條流程、講師、梯次、聯絡)
    設計風格.md          → 主色、質感、字體、避開什麼
    素材/
      logo.png
      og.png

  2. 產出/                → Cloudflare 部署的實際檔案
    index.html
    assets/
```

## 對照建議

如果你要建自己的新專案:

1. 先看 `1. 素材資料/課程.md` 的「學員帶走什麼」— 3 條自動化流程 怎麼寫得具體、有數字、有畫面
2. 再看 `2. 產出/index.html` — 從素材變成的完整網站
3. 覺得 OK 就複製 `專案/範本/` 開始填自己的

## 更新規則

`2. 產出/` 這一份是 **snapshot 快照**,跟 repo root 的 `course/` 內容一致。
如果 live 站(`course/`)有更新,想同步這裡的快照,跟 Claude 說「同步 製造業課程 產出」即可。
