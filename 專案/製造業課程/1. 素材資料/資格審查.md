# 資格審查

**本專案有跑統編驗證** — g0v 公開資料 API + 使用者自行勾選勞工投保人數。

---

## 檢查項目(4 條,全過才能報名)

- [x] 公司必須是「營業中」(不能是歇業/解散/撤銷/廢止/停業)
- [x] 必須是製造業(C 大類,行業代碼前 2 碼 08~34)
- [x] 必須是工具機上下游(要求對應到工具機代碼白名單)
- [x] 勞工投保人數 200 人以下(**使用者在 STEP 1 自行勾選**,經濟部資料無此欄位)

## 資料來源

- `https://company.g0v.ronny.tw/api/show/{8碼統編}` (g0v 社群公開 API)
- 從 API 回傳撈:公司名稱 / 登記現況 / 財政部行業 / 所營事業資料
- **不再撈資本額**(已於 2026-07 移除,理由:改用勞工投保人數當中小企業門檻)

## 判定等級

| 等級 | 條件 | 能不能報名 |
|---|---|---|
| 🟢 完全符合資格 | 工具機 + 營業中 + ✓ 已勾勞保 | **能** |
| 🟡 部分符合(製造業) | 製造業 + 營業中 + ✓ 已勾勞保 | 不能,聯絡顧問 |
| 🟡 部分符合(未勾勞保) | 製造業或工具機 + 營業中 + ✗ 未勾勞保 | 不能 |
| 🟡 部分符合(單一條件) | 製造業或工具機(其他沒過) | 不能 |
| 🔴 暫不符合 | 都沒過 | 不能 |

## 工具機上下游代碼白名單

寫在 `course/index.html` 的 `CONFIG.TOOL_MACHINE_CODES` 陣列裡,約 30~40 個代碼。若要增減,直接改該陣列。

## 製造業大類代碼

C 大類 08~34(綜合、金屬、機械、電子、化工、食品等),寫在 `CONFIG.MANUFACTURING_CODES`。
