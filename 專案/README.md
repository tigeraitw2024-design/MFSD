# 專案資料夾

未來要幫其他中心、協會、公司做課程網站,把資料丟這裡,叫 Claude 就好。

## 結構

```
專案/
  範本/                   ← 空白樣板,複製它開始
    1. 素材資料/          ← 你填的地方
    2. 產出/              ← Claude 建好的網站放這

  [新專案名]/             ← 每個新客戶一個(中文命名也可以)
    1. 素材資料/
    2. 產出/
```

## 怎麼用

1. **複製 `範本/` 為 `專案/[新專案名]/`**
   命名建議直接用中文,例如 `亞太物聯協會`、`AX 學院`、`製造業課程`

2. **打開 `1. 素材資料/` 資料夾,把裡面的檔案填一填**
   - 必填 4 個:`品牌.md` / `課程.md` / `情境.md` / `聯絡.md`
   - 選填的沒填會用預設,不會出錯

3. **對 Claude 說任一句就開工**:
   - `跑 [專案名]`
   - `幫 [專案名] 建站`
   - `用 專案/[專案名] 生網站`

Claude 會先讀完素材資料 → 檢查完整度 → 跟你確認缺什麼 → 同意後才動筆
產出丟在同資料夾的 `2. 產出/` 底下,不會影響現有網站。
