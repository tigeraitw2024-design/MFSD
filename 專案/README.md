# 專案資料夾

未來要幫其他中心、協會、公司做課程網站時,把資料丟這裡,叫 Claude 就好。

## 你只要準備 2 樣東西

- **`課程.md`** — 課程資訊
- **`設計風格.md`** — 想要的視覺風格

其他所有細節(統編驗證規則、確認信文案、章節微調、資格審查 …)**在對話裡跟 Claude 慢慢調就好**,不用事先想清楚。

## 資料夾結構

```
專案/
  範本/                   ← 空白樣板,複製它開始
    1. 素材資料/
      課程.md             ← 你填
      設計風格.md         ← 你填
      素材/               ← 選填 logo / hero / og
    2. 產出/              ← Claude 建的網站放這

  製造業課程/              ⭐ 完整範例(參考用)
    1. 素材資料/          兩個檔案都已填滿
    2. 產出/              mfsd.pages.dev/course/ 的完整 snapshot

  規範/                    ← Claude 建站時遵守的規則(你不用改)
    文案原則.md
    頁面結構.md
    視覺系統.md
    部署清單.md
```

## 怎麼用

1. **複製 `範本/` 為 `專案/[新專案名]/`**
   命名建議直接用中文,例如 `亞太物聯協會`、`AX 學院`

2. **填 `1. 素材資料/課程.md` 跟 `設計風格.md`**
   對照 `製造業課程/` 那份參考範例

3. **對 Claude 說任一句就開工**:
   - `跑 [專案名]`
   - `幫 [專案名] 建站`
   - `用 專案/[專案名] 生網站`

Claude 會先讀完素材、跟你確認缺什麼、有沒有理解錯,同意後才動筆產出到 `2. 產出/`。
之後其他細節(要不要加統編驗證、確認信要不要改、章節要不要調整),在對話裡慢慢說就好。
