# 專案資料夾

未來要幫其他中心、協會、公司做課程網站時,把資料丟這裡,叫 Claude 就好。

## 你只要準備 2 樣東西

- **`課程.md`** — 課程資訊
- **`設計風格.md`** — 想要的視覺風格

其他所有細節(統編驗證規則、確認信文案、章節微調、資格審查 …)**在對話裡跟 Claude 慢慢調就好**,不用事先想清楚。

## 資料夾結構

專案分 **課程** 跟 **活動** 兩類:

```
專案/
  課程/                            ← 課程類網站(有報名表、Apps Script、梯次)
    範本/                          ← 空白樣板,複製它開始
      1. 素材資料/
        課程.md                    ← 你填
        設計風格.md                ← 你填
        素材/                      ← 選填 logo / hero / og
      2. 產出/                     ← Claude 建的網站放這
    1_製造業課程/                   ⭐ 完整範例(參考用)
    2_在職菁英課程/
    3_企業落地/
    4_製造業列車(MORRIS)/
    5_AI 升級計劃/
    6_AI 智造落地/
    7_製造業列車(Victor)/
    8_AI工作流程/

  活動/                            ← 活動類網站(說明會、研討會、單場活動)
    (之後有活動專案才會長出範本與資料夾)

  規範/                            ← Claude 建站時遵守的規則(你不用改)
    文案原則.md
    頁面結構.md
    視覺系統.md
    部署清單.md

  sync_media_manifest.py           ← Drive 照片輪播同步工具(課程網站共用)
  sync_photos.py                   ← 舊版照片下載工具
```

## 怎麼用(課程)

1. **複製 `課程/範本/` 為 `課程/[新專案名]/`**
   命名建議直接用中文,例如 `亞太物聯協會`、`AX 學院`

2. **填 `1. 素材資料/課程.md` 跟 `設計風格.md`**
   對照 `課程/1_製造業課程/` 那份參考範例

3. **對 Claude 說任一句就開工**:
   - `跑 [專案名]`
   - `幫 [專案名] 建站`
   - `用 專案/課程/[專案名] 生網站`

Claude 會先讀完素材、跟你確認缺什麼、有沒有理解錯,同意後才動筆產出到 `2. 產出/`。
之後其他細節(要不要加統編驗證、確認信要不要改、章節要不要調整),在對話裡慢慢說就好。

## 怎麼用(活動)

活動類網站規模通常比課程小(只有活動頁 + 報名)、沒有梯次、沒有多講師。
目前還沒有活動範本 · 第一個活動網站做完後會沉澱出範本。

要新增活動時 · 直接跟 Claude 說「要新增一個活動網頁」· 給一份活動資訊 md · Claude 會直接做在 `專案/活動/[活動名]/`。
